# Бэкенд расписания

FastAPI + SQLAlchemy + PostgreSQL. Отдаёт готовое расписание группы на неделю:
чётность, сроки действия пар и сортировка уже применены, фронтенд только рисует.

## Что уже есть

| Слой | Файл | Назначение |
|---|---|---|
| Парсер Excel | `app/services/excel_parser.py` | разбор файла расписания ИИТ в структуры данных, без обращений к БД |
| Импорт в БД | `app/services/importer.py` | справочники, группы, постоянные пары |
| Календарь недель | `app/services/weeks.py` | номер, чётность и даты недели |
| Сборка недели | `app/services/schedule.py` | отбор пар группы на неделю |
| API | `app/api/v1/public.py` | публичные эндпоинты для студента |

## Запуск

### Вариант 1: Docker Compose (из корня репозитория)

```bash
docker compose up -d --build
docker compose exec backend python -m app.cli seed-semester
docker compose exec backend python -m app.cli import-excel "/app/../Расписание_ИИТ_1_сем_26_27_уч_г_РАБОЧИЙ_ВАРИАНТ.xlsx"
```

### Вариант 2: локально

```bash
cd backend
python -m pip install -r requirements.txt
cp .env.example .env            # и поправить DATABASE_URL под свой Postgres

python -m alembic upgrade head               # схема БД
python -m app.cli seed-semester              # активный семестр + сетка звонков
python -m app.cli import-excel "../Расписание_ИИТ_1_сем_26_27_уч_г_РАБОЧИЙ_ВАРИАНТ.xlsx"
python -m app.cli stats                      # что получилось

uvicorn app.main:app --reload                # http://localhost:8000/docs
```

Без Postgres под рукой можно поднять на SQLite:

```bash
DATABASE_URL="sqlite+pysqlite:///./schedule.db" python -m app.cli init-db
```

## Команды CLI

| Команда | Что делает |
|---|---|
| `python -m app.cli init-db` | создать таблицы по моделям (альтернатива Alembic) |
| `python -m app.cli seed-semester` | завести активный семестр, сетку звонков и форматы пар |
| `python -m app.cli import-excel <путь>` | разобрать Excel и залить расписание (повторный запуск заменяет пары семестра) |
| `python -m app.cli stats` | сводка по базе: группы, пары, справочники |

Параметры семестра по умолчанию: `1 семестр 2026/27`, начало 1 сентября 2026,
18 недель, первая неделя нечётная. Меняются флагами:
`seed-semester --title "..." --start 2026-09-01 --weeks 18 --parity odd`.

## API

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/health` | проверка живости |
| GET | `/api/v1/groups` | список групп (id, name, course) |
| GET | `/api/v1/time-slots` | сетка звонков, нужна фронту для сетки недели |
| GET | `/api/v1/weeks/current` | номер, чётность и даты текущей недели |
| GET | `/api/v1/groups/{group_id}/schedule?week=N` | **расписание группы на неделю**; без `week` — текущая |

Структура ответа — в `03-schedule-json.md`. Интерактивная документация: `/docs`.

## Формат Excel

Парсер опирается на такую раскладку листа:

* один лист — один курс, 2-3 группы на листе;
* строка-шапка с названиями групп (ищется автоматически, обычно 15-я),
  каждая группа занимает два столбца — подгруппы;
* столбец с днями недели, справа от него столбец с номерами пар (1-8);
* внутри блока «день + номер пары» пара описана двумя строками:
  название и «преподаватель, должность, АУД. номер».

Что распознаётся:

| В файле | Как сохраняется |
|---|---|
| `1Н.` / `2Н.` / без префикса | `week_parity` = `odd` / `even` / `both` |
| `(ЛЕК.)`, `(ПР.)`, `(ЛАБ.)`, `(ЛЕК.+ПР.)` | `lesson_type` |
| `(9-15 НЕД.)` | `week_from`/`week_to` и срок действия `valid_from`/`valid_to` |
| `с 19:00` в начале ячейки | пара вне сетки: своё время, `slot = null` |
| `АУД. 132Б`, `ФОК` | аудитория; без них — `null` (онлайн-курс) |
| перенос названия на вторую строку | склеивается в одно название |
| два преподавателя через запятую | одна строка `ФИО, ФИО` |
| `ДЕНЬ САМОСТОЯТЕЛЬНЫХ ЗАНЯТИЙ`, подписи, сноски | отбрасывается |

Ячейки, которые не удалось разобрать однозначно, попадают в
`schedule_imports.errors` — их видно в отчёте импорта.

## Тесты

```bash
python -m pytest tests -q
```

Сквозные тесты берут настоящий Excel из корня репозитория; если файла нет,
они пропускаются.

## Чего ещё нет

Временные изменения (`lesson_overrides`), админка, загрузка Excel через API,
авторизация. У всех пар в ответе `status = "regular"`, `change = null`.
