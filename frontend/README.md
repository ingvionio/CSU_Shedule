# Фронтенд расписания

React + TypeScript + Vite. Экран студента: расписание своей группы на день и
на неделю. Все данные приходят с бэкенда готовыми — фронт ничего не вычисляет.

## Запуск

```bash
npm install
cp .env.example .env.local     # если бэкенд не на http://localhost:8000
npm run dev                    # http://localhost:5173
```

Бэкенд должен быть запущен и наполнен (см. `../backend/README.md`).
Порт фронта должен быть указан в `CORS_ORIGINS` бэкенда — по умолчанию там
разрешены `http://localhost:5173` и `http://127.0.0.1:5173`.

```bash
npm run build      # сборка в dist/
npm run preview    # посмотреть собранное
```

```

  styles.css
```

## Что делает приложение

| Экран | Что показывает |
|---|---|
| Выбор группы | курс -> направление -> группа, список приходит из `GET /groups`; выбор сохраняется на устройстве |
| На день | полоса дат недели, пары выбранного дня; по умолчанию открывается сегодня |
| На неделю | сетка по сетке звонков, линия текущего времени, горизонтальная прокрутка |
| Карта | навигатор map.csu.ru: поиск аудиторий, этажи и маршруты |

Карта открывается отдельным экраном через iframe. Нижнее меню расписания
на этом экране скрыто, возврат — стрелкой сверху. При возврате и повторном
открытии карта сохраняет выбранный маршрут. Справа сверху можно открыть
оригинал в отдельной вкладке. Карта требует интернета и доступна даже при
ошибке API расписания; код и данные навигатора загружаются с map.csu.ru.

Переключение недель — кнопками или свайпом по полосе дат, по полям
`week.prev` / `week.next` из ответа бэкенда.

Последний полученный ответ сохраняется в `localStorage`, поэтому расписание
открывается и без сети; при появлении связи данные обновляются.

## Что отображается у пары

Номер пары показывается, только если `slot` не `null` — пара вне сетки
(например, в 19:00) показывается одним временем. Формат пары берётся из
`type.name`, чтобы новые форматы не ломали экран. Подгруппа из Excel
показывается пометкой «1 подгруппа», если она указана.

Изменённые пары помечаются по `status`; под названием выводятся пояснения:
куда/откуда перенесена, что было до замены, комментарий админа.

## Админка

Меню в шапке → «Администрирование расписания» → вход по логину и паролю
(токен хранится на устройстве до истечения). Дальше — сетка недели группы:

* клик по паре — отменить, перенести, заменить аудиторию/преподавателя/время,
  а у уже изменённой пары — откатить изменение;
* клик по пустой клетке — доп. пара;
* режим «Поток» — то же действие сразу для нескольких групп курса.

Все изменения сохраняются на бэкенде (`POST/DELETE /admin/overrides`) и сразу
видны студентам; после ответа все недели перезапрашиваются. Ошибки бэкенда
(пересечение по времени, нет такой пары у группы потока) показываются в диалоге.
