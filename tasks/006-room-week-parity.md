# 006 — Разные аудитории по чётности недели

## Требования

Поручение пользователя: запись «АУД. 425/201» означает аудиторию 425 по нечётным неделям и 201 по чётным. Пример: группа ИТ1-ПрИб-11, лист «ПрИ-11,12», предмет «Основы российской государственности».

## Вопросы к архитектору

Нет для указанного формата.

## Отчёт

- Парсер создаёт два варианта занятия для записи двух кабинетов через `/`: первый — odd, второй — even. Для пары с явным префиксом 1Н./2Н. оставляет только соответствующий кабинет.
- Сохраняются время, преподаватель, предмет, подгруппа, сроки действия и ссылка на исходную ячейку. Схема БД и контракт недели не изменены.
- Файлы: `backend/app/services/excel_parser.py`, `backend/tests/test_room_parity.py`.
- Добавлены 7 тестов: варианты кабинетов с пробелами и буквами, префиксы чётности, обычный кабинет, импорт с повторной загрузкой и сборка расписания для трёх недель.
- На предоставленном Excel подтверждено: лист «ПрИ-11,12», C40–C41, вторник, 2-я пара — odd/425 и even/201. Рабочий Excel не копировался в репозиторий, база приложения не изменялась.
- При разборе исходного файла получено 336 вариантов занятий и 1 диагностическое сообщение парсера; другие неоднозначные форматы не входят в это исправление.
- Новых зависимостей и миграций нет. Фронтенд не изменён. Для уже загруженного расписания необходим повторный импорт исходного файла, чтобы обновить кабинеты.
- Коммит не создавался.
- Проверки: полный pytest — 217 passed, 54 skipped; git diff --check — успешно.
