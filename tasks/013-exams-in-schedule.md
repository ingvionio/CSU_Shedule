# 013 — Экзамены в обычном расписании вместо отдельного режима «Сессия»

Ветка `feature/session-schedule`. Исправление решения 3 задачи 010
(уточнение Лёши 21.11.2026): **отдельного режима «Сессия» у студента нет.**
События сессии и пересдач (`exam_events`) показываются прямо в расписании
«На день» и «На неделю» среди пар, с заметной пометкой, что это экзамен /
консультация / зачёт / пересдача. Раздел «Сессия» в админке (загрузка,
правка) остаётся как есть.

## Требования

### 1. Сборка недели и дня (`app/services/schedule.py`)

- `_assemble_days` получает флаг `include_exams` (по умолчанию `False`).
  `True` — только для студенческой недели/дня (`GET /groups/{id}/schedule`,
  и то, что использует фронт для «На день»). Проверка пересечений в
  `overrides.py`, личные заметки (`notes.py`) и неделя потока
  (`stream_schedule.py`) — **без** экзаменов: экзамен не должен давать 409
  при добавлении пары и не попадает в сравнение потока.
- События группы на даты недели (пн–сб; событие в воскресенье — тоже
  показать, добавив воскресенье в `days` только если в нём есть событие)
  встают в `days[].lessons[]` элементом:

  | Поле | Значение |
  |---|---|
  | `id` | `e-{exam_event.id}` |
  | `start_time` | `HH:MM` или **`null`** (время не указано) |
  | `end_time` | `null` (длительность неизвестна) |
  | `slot` | номер пары, если `start_time` совпадает с началом пары в сетке звонков, иначе `null` |
  | `subject`, `teacher`, `room` | из события |
  | `online_url` | `null` |
  | `type` | `{code, name}`: `exam` «Экзамен», `consultation` «Консультация», `credit` «Зачёт», `graded_credit` «Дифф. зачёт», `other` «Аттестация»; у пересдач — `retake` «Пересдача» |
  | `status` | `regular` \| `changed` \| `cancelled` (как в 010) |
  | `change` | для `changed`: `{"original": {…}}` — только изменённые поля из `exam_events.original` (`date`, `start_time`, `room`) |
  | `stream_diff` | `null` |
  | `event` | **новое**, у пар — `null`; у событий — `{"kind": "session"\|"retake", "note": str\|null, "groups": [имена всех групп события]}` |

  Сортировка дня: события без времени — первыми, дальше всё по `start_time`.
- **Диапазон недель.** Сессия часто после последней учебной недели (январь,
  июнь). Последняя доступная неделя = max(`total_weeks`, неделя последнего
  события `exam_events` активного семестра). `week.next`/`prev`, проверка
  номера недели в `build_week_schedule` и «текущая неделя» по умолчанию
  считаются в этом расширенном диапазоне (функции в `weeks.py`/`schedule.py`,
  одна точка расчёта). Чётность — по-прежнему от начала семестра.
- `week.schedule_pending` (011): неделя, где есть только события сессии, —
  не «ожидание расписания» (`false`).

### 2. Убрать отдельный режим

- Бэкенд: удалить `GET /groups/{group_id}/exams`, `GroupExamsOut` и связанное,
  если больше нигде не используется; тесты перенести на выдачу недели.
- Фронт: удалить вид `exams` (кнопку «Сессия» в переключателе «На день / На
  неделю», `StudentExams`, `ExamCard`, запрос/хук). Старый адрес `#/exams`
  открывает «На день».

### 3. Отображение (фронт, `ScheduleComponents.tsx`, `styles.css`)

- Карточка события в «На день» — та же карточка пары, плюс:
  бейдж вида (`type.name`); экзамен/зачёт/пересдача — акцентный цвет (тёплый,
  отличимый от «изменено»/«отменено»), консультация — спокойнее; время
  «15:00» без конца, без времени — «Время не указано»; примечание
  (`event.note`) — выделенным блоком; «Вместе с …» — другие группы из
  `event.groups` (без своей); прежние значения из `change.original` —
  зачёркнуто, как у пар; отменённое — зачёркнуто с «отменено».
- «На неделю» (сетка по парам): событие со `slot` — в своей ячейке; с
  временем вне сетки — в ближайшей по времени (как пары вне сетки сейчас);
  без времени — полоской вверху дня. Везде тот же бейдж и цвет.
- Админская сетка «Расписание» (разовые изменения): события видны, но **не
  кликаются** для правки пары — подсказка «Правится в разделе „Сессия“».
- Фронт ничего не вычисляет: тип, цвет по `type.code`, позиция по `slot`.

### 4. Тесты

- неделя с парами и событиями: порядок, поля элемента события, `slot` по
  совпадению с сеткой, событие без времени — первым;
- `changed` с `change.original`, `cancelled`;
- пересдача — `type.code = retake`;
- событие у двух групп видно обеим, у третьей — нет;
- расширенный диапазон: последняя неделя = неделя последнего события,
  `next` у последней учебной недели не `null`, запрос дальней недели — 200,
  ещё дальше — ошибка как раньше; без событий — диапазон прежний;
- добавление пары в админке в то же время, что экзамен, — без 409;
  неделя потока экзаменов не содержит;
- `schedule_pending = false` у магистров, если в неделе только экзамен;
- `npm test`, `npm run build`.

Что сделано:

- События сессии и пересдач включены в публичную неделю группы и расписание дня. Добавлены `event`, nullable-время, типы, статусы и `change.original` только с исходными изменёнными полями.
