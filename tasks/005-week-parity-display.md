# 005 — Чётность рядом с номером недели

## Требования

По поручению пользователя: показывать чётность везде, где интерфейс выводит номер недели. Парсинг расписания и аудиторий не менять.

## Вопросы к архитектору

Нет.

## Отчёт

- В заголовке расписания администратора добавлена подпись «чётная» / «нечётная» из готового ответа API.
- В таблице проверки и результата понедельной загрузки добавлена такая же подпись. API отчёта расширен полем `parity`: сервер использует существующий календарь семестра `parity_of_week`. Для неопределённой или выходящей за границы семестра недели возвращается null.
- Студенческий экран уже показывает чётность; других мест вывода номера недели в TSX не обнаружено.
- Изменены: `backend/app/schemas/imports.py`, `backend/app/services/admin_imports.py`, `backend/tests/test_admin_imports.py`, `frontend/src/api/types.ts`, `frontend/src/pages/admin/AdminImports.tsx`, `frontend/src/pages/admin/AdminSchedule.tsx`.
- Добавлены проверки чётности отчёта для семестров с нечётной и чётной первой неделей, а также неизвестной недели повреждённого файла.
