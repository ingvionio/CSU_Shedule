# Справки на почту методиста и файлы в ответах

Заявки на справки приходят методисту на почту в формате учебной части. Методист может прикрепить к ответу файл (скан справки): он виден студенту в приложении и приходит вложением на почту.

## Формат письма методисту

```
Заявка на справку о том, что студент.
1. ФИО студента
2. Группа
3. В какое учреждение требуется
4. Кол-во: N шт.
5. Способ получения: «Заберу лично в учебной части», «Требуется скан на эл.почту: <почта>» или «Отправить почтой РФ, адрес: <адрес с индексом>»
```

Дополнительная информация студента, если есть, идёт после пункта 5. Тема: `[Расписание] Заявка на справку №N · группа · ФИО`. Если студент оставил почту, она стоит в Reply-To.

## Отчёт

- Форма справки: пункты «В какое учреждение требуется», «Количество справок», «Способ получения» (обязательный выбор из трёх). Для Почты России обязателен адрес с индексом, для скана — почта. Для остальных способов почта необязательна: на неё придёт ответ.
- API `POST /feedback` (kind `certificate`) принимает `delivery` (`pickup` | `scan` | `post`), `address`, `email`. Почта хранится в `contact`, как у обычных обращений.
- Заявка ставит письмо адресату «Методист» (`backend/app/services/feedback.py`, `certificate_letter`). Раньше заявки на почту не уходили.
- Ответ с файлами: `POST /admin/feedback/{id}/replies/files` (multipart: `text`, `files`). До 5 файлов, каждый до 10 МБ, вместе до 20 МБ (у Яндекса лимит письма 30 МБ, base64 добавляет треть). Типы по расширению: PDF, JPG, PNG, HEIC, DOC, DOCX, ODT, RTF. Проверка прав админа — до чтения multipart (`core/http_security.py`).
- Файлы хранятся в базе (`feedback_attachments`): выкладка заменяет папку бэкенда целиком, а дамп базы сохраняет и файлы.
- Скачивание: студент — `GET /feedback/attachments/{id}` (только свои обращения, иначе 404), админ — `GET /admin/feedback/attachments/{id}`. Ответ с `Content-Disposition: attachment`, `nosniff`, `no-store`.
- Письмо студенту с ответом получает файлы вложением (`email_outbox.reply_id`). Worker читает вложения по одному письму.
- Исправлено: в письме об ответе на справку стояло «Справка ответил…», теперь «Методист ответил на вашу заявку на справку».
- Миграция `fc61d2a7e930`: `certificate_delivery`, `certificate_address`, таблица `feedback_attachments`, `email_outbox.reply_id`. Только добавления.

### Ограничения

- В APK (Android WebView) скачивание файла через кнопку может не сработать: WebView не обрабатывает загрузку blob-ссылок без доработки нативной части. Студент получает файл на почту; в веб-версии скачивание работает.
