# 004 — Навигация по текущему дню и оформление студенческих экранов

## Поручение пользователя

- Добавить рядом с переключением недель кнопку «Сегодня», возвращающую к текущим неделе и дню.
- При запуске выбирать сегодняшний день.
- Выделять сегодня заметнее точки.
- Убрать «Профиль» из шапки и «Студенческое расписание» из меню.
- Выровнять кнопки профиля, сделать выход красным.
- Увеличить отступ нижней навигации от системной полоски iPhone.

## Вопросы к архитектору

- В текущем контракте расписания доступны понедельник–суббота. Как должен работать переход «Сегодня» в воскресенье? Состав дней в этой задаче не изменён.

## Отчёт

- Добавлена кнопка «Сегодня»: выбирает текущую неделю из API и режим дня, обновляет данные. Выбор сегодняшнего дня реагирует также на изменение `is_today` после обновления кеша. Сохранённый номер текущей недели перепроверяется при запуске.
- Сегодня подписано текстом и выделено рамкой; выбранный сегодняшний день имеет насыщенный фон. Добавлены `aria-current` и `aria-pressed`.
- Убраны два указанных дублирующих перехода. Гостевая кнопка «Войти» сохранена.
- Кнопки профиля имеют равные ширину и высоту; выход — красный.
- Добавлены нижний отступ 16px сверх safe area, соответствующий отступ контента и `viewport-fit=cover`.
- Файлы: `frontend/src/App.tsx`, `frontend/src/api/queries.ts`, `frontend/src/styles.css`, `frontend/index.html`.
- Проверка: `npm test` — 7 тестов прошли; `npm run build` — успешно. В браузере проверены переход на следующую неделю и возврат на сегодня, выбор другого дня и перезагрузка, профиль и меню.
- На физическом iPhone не проверено: требуется оценить отступ в установленной PWA.
- Новых зависимостей нет. Коммиты не создавались.
